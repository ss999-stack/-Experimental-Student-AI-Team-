# Student Agent Project

An early-stage, text-based project exploring how AI agents can help students organize coursework, review handwritten notes, plan study sessions, and adjust when plans change.

The project includes prompts for coordination, note review, planning, recovery, and verification. These prompts are used manually in an AI assistant; automated integrations are planned for future development.

The goal is to build an open, documented setup that students can copy and adapt to their own semester.
